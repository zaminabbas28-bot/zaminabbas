# Site photos

Drop your photos in **this folder** — no code changes needed. The site
automatically picks them up (JPG, JPEG, PNG or WebP — just keep the file name).

| File name | Shows in            | Recommended size              |
| --------- | ------------------- | ----------------------------- |
| `hero`    | Hero card portrait  | 800 × 800 px (shown in a circle) |
| `about`   | About section photo | 600 × 600 px (square)            |

Example: save your portrait as `hero.jpg` (or `hero.webp`) in this folder and it
appears in the hero card.

Tips:
- **WebP** format + compressed (each file under ~200 KB) keeps the site fast —
  speed is part of SEO.
- Until you add a file, the gold "ZA" monogram shows in its place, so the site
  always looks complete.
- Want photos anywhere else (service cards, testimonials)? Just say the word.
